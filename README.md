# 小红书下载器

把喜欢的小红书**图文、视频、实况 Live 图**保存成无水印文件的个人自用小工具（Windows）。

- 免登录：平时全程用平台分配的游客身份，不需要注册/登录
- 无水印原图：图片保存作者上传的原始分辨率；视频保存平台提供的最高画质（一般 1080p，小红书无 4K）
- 实况图：自动成对保存「图 + 带声音的小视频」（01.jpg + 01.mov）
- 解析预览：粘贴分享链接后先看封面/标题/作者，勾选后再下载
- 批量下载自动放慢节奏防风控；重复下载自动跳过

## 下载安装

到 [Releases 页面](https://github.com/yuanyuandada/xhs-downloader/releases/latest) 下载「小红书下载器安装包.exe」，双击 → 下一步 → 装好，桌面出现图标。

首次运行如果 Windows 弹蓝色提示"已保护你的电脑"，点 **更多信息 → 仍要运行**（本工具未购买数字签名，属正常现象）。

## 使用

1. 在小红书 App 打开笔记 → 分享 → 复制链接
2. 粘贴到输入框 → 点「解析预览」
3. 勾选想要的笔记 → 点「开始下载」

详见仓库内的 [使用说明.md](使用说明.md)。
